# ChinaDrop UA — Сайт-посередник Pinduoduo & Taobao для України

Повністю готовий статичний веб-додаток (HTML + CSS + JS), який працює без встановлення додаткових залежностей.

## Як запустити:
1. Розпакуйте архів `chinadrop-ua-site.zip`.
2. Відкрийте файл `index.html` у будь-якому сучасному браузері (Chrome, Edge, Safari, Firefox) або завантажте папку на будь-який хостинг (Vercel, Netlify, GitHub Pages).

## Демо-доступи:
- **Адмінка власника**: Логін `admin`, пароль `admin` (або кнопка «👑 Власник / Адмін» у вікні входу).
  - Видно всю історію замовлень клієнтів, ваш чистий заробіток з комісії, зміну статусів замовлень, експорт у CSV та налаштування тарифів Meest China і відсотка комісії.
- **Акаунт покупця**: Логін `user@example.com`, пароль `user` (або вільна реєстрація нового акаунту).
- **Відгуки**: зберігаються у `localStorage` браузера, адмін може видаляти спам-відгуки.
