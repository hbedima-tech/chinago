# ChinaDrop UA — Pinduoduo & Taobao Archive Storefront

Повноцінний веб-додаток для замовлення одягу, взуття, прикрас, аксесуарів та чохлів з китайських майданчиків **Pinduoduo** та **Taobao** для клієнтів в Україні з автоматичним розрахунком доставки **Meest China** у гривнях, системою акаунтів, відгуками та панеллю власника.

## Можливості
- **Каталог Archive & Streetwear (18+ лотів)** з розподілом по категоріях (`Взуття`, `Штани`, `Кофти`, `Футболки`, `Прикраси`, `Аксесуари`, `Чохли`).
- **Надійні зображення + локальні SVG-рендери** — картинки ніколи не зникають навіть без інтернету або при блокуванні зовнішніх CDN.
- **Актуальні тарифи Meest China (2026)**:
  - Авіа (Нова Пошта / відділення Meest): **$17.6 – $18.1 / кг** (9–12 днів)
  - Море: **$6.1 – $6.4 / кг** (35–45 днів)
  - Детальний фотозвіт зі складу в Гуанчжоу: **$1.5 / лот**
- **Система акаунтів (Покупці + Адмін)**:
  - Реєстрація та вхід користувачів (`localStorage`), збереження даних Нової Пошти та Telegram, історія замовлень зі статусами, список обраного.
  - Вхід у 1 клік під демо-акаунтом покупця або адміністратора.
- **Система відгуків з оцінками та тегами батчів**:
  - Кожен лот має рейтинг, перевірені відгуки клієнтів з України та форму додавання нового відгуку з вибором оцінки, розміру та тегу якості (`Топ батч 1:1`, `Ідеальний розмір`, `Швидка доставка`, `Товстий бавовник`).
- **Викуп за власним посиланням** з автоматичним калькулятором ціни під ключ.
- **Кабінет власника (Admin Panel)**:
  - Налаштування % комісії сервісу, курсу юаня (`¥ -> ₴`), тарифів доставки, аналітика прибутку та модуль імпорту лотів через API агрегатори (`TMAPI / OTAPI / RapidAPI`).

## Як запустити локально

1. Встановіть **Node.js** (версія 18 або новіша).
2. Відкрийте папку проєкту в терміналі та виконайте:
   ```bash
   npm install
   npm run dev
   ```
3. Відкрийте посилання `http://localhost:5173` у браузері.
